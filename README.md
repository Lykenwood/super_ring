# 进度边栏

独立 Android App，不修改 `notification-demo`。读取其他 App 通知中的 `EXTRA_PROGRESS` 与 `EXTRA_PROGRESS_MAX`，显示屏幕边栏条、摄像头挖孔圆环或环绕屏幕的圆角矩形进度条。支持手动 HSV 色盘、`#AARRGGBB` 八位十六进制输入、不透明度调节、通知来源图标配色、前台应用图标配色、持续 100% 预览。适应颜色可选择只取主色、主辅双色、显示所有占比超过 10% 的颜色，或按图标颜色位置渐变；通知带大图标时优先用大图标取色。

边栏条可设置上/下/左/右位置、X/Y 偏移、长度和正反进度方向。挖孔圆环可分别设置竖屏与横屏的 X/Y 偏移，并设置半径、起始角和顺/逆时针；原有偏移保留为竖屏值，横屏初始偏移为 0。环绕屏幕条可设置宽度、高度、X/Y 偏移、圆角、独立粗细、起始角和顺/逆时针。所有设置项均有独立重置按钮；数值滑杆有加减按钮，步进为 0.2 dp 或 0.2°；点击滑条下方的数值可直接输入，仍按 0.2 步进和当前范围校验。颜色不透明度的数值也可点击输入百分比。半径、边栏长度、环绕屏幕宽高的“自动”值为 0。环绕屏幕宽高的手动值以整屏悬浮层尺寸为基准，不被系统栏之间的可用区域提前截断；宽高滑杆最大值为屏幕长边的 150%，超过屏幕的部分会被裁切。自动值仍按安全可见区域计算。Android 11 及以上的悬浮层使用独立窗口上下文，以跟随显示区域变化。

用 Android Studio 打开本目录。“首页”管理可同时显示的多个实例，可新增、编辑、启停、复制、排序和删除；每个实例独立保存样式、位置、颜色、光晕和预览设置。编辑页分为“类型”“位置与大小”“颜色”三个选项卡；类型页包含强制显示和进度方向，颜色页先选指定颜色或适应颜色，适应颜色再选来源与取色方式。旧版单实例设置会自动迁移为“原有进度条”，已有取色方式编号继续兼容。多个实例共用一个不可触摸悬浮窗口，避免多个全屏窗口叠加被系统判定为遮挡触摸。当前所有实例共享“自动选择最新标准进度通知”的进度值，数据结构已为未来逐实例指定来源预留字段。“我的”页显示悬浮窗、通知使用权、前台应用配色服务的状态，并提供系统设置入口与重新检查按钮，还可切换全局深色模式。新版会区分无障碍服务“系统已开启”和“实际已连接”；从系统设置返回时会自动更新状态。首页总开关关闭后，全部悬浮层会立即移除，通知和无障碍服务暂停处理事件；再次开启时会重新读取当前通知。`artifacts/` 是旧版 APK 留档，不代表当前源码。

首次使用需分别在系统设置中开启“显示在其他应用上层”和“通知使用权”。前台应用配色还需开启单独的无障碍服务；该服务只接收窗口切换事件中的应用包名，不读取窗口内容。可用同级的 `notification-demo` 应用产生测试进度通知。预览开关关闭后，只有检测到带标准进度字段的通知才会显示。图标颜色会先将近似颜色分组；10% 阈值按不透明像素的色组面积计算，位置渐变沿图标横向、纵向或环向采样。读取不到来源图标时尝试通知强调色，仍不可用则使用默认浅灰色 `#EEEEEE`；新实例的手动默认色和“颜色”重置值也是 `#EEEEEE`。自定义通知和播放器进度目前不识别。普通悬浮窗位于系统状态栏下方，挖孔区域是否可见取决于设备系统。

悬浮窗使用不可触摸窗口标志。前台应用配色无障碍服务连接时使用受系统信任的无障碍悬浮层，保持线条设置的原始不透明度；服务未连接时，Android 12 及以上会将普通悬浮窗的窗口不透明度限制在触摸穿透阈值内，避免整屏悬浮窗阻挡下层弹窗点击，此时线条显示会略淡。发光效果默认关闭，打开后可跟随线条颜色或指定独立颜色，并调整扩散大小和不透明度。粗细可设为 0，只显示光晕。图标或手动颜色变化时，线条和跟随色光晕按各实例设置的时长过渡；默认 200 毫秒，可在 0–5000 毫秒之间调整，0 表示立即切换；系统关闭动画时也会直接切换。环绕屏幕条在横屏自动交换自定义宽高。
